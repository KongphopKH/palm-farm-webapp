# วิธีเพิ่มสกรีนช็อตในหน้า README หลัก

1. เปิดเว็บที่ deploy จริง (ที่มีข้อมูลตัวอย่างอยู่แล้ว จะดูน่าสนใจกว่าหน้าจอว่างเปล่า)
2. ถ่ายภาพหน้าจอ 3 หน้านี้ (แนะนำถ่ายจากมือถือ หรือย่อเบราว์เซอร์ให้แคบแบบมือถือก่อนถ่าย
   เพราะแอปออกแบบมาสำหรับหน้าจอมือถือ):
   - หน้าแรก (Dashboard) → บันทึกเป็น `dashboard.png`
   - หน้าปฏิทิน (`/calendar`) → บันทึกเป็น `calendar.png`
   - หน้าบัญชีฟาร์ม (`/finance`) → บันทึกเป็น `finance.png`
3. วางไฟล์ทั้ง 3 ไว้ในโฟลเดอร์นี้ (`docs/screenshots/`) ใช้ชื่อไฟล์ตรงตามด้านบน
4. เสร็จแล้ว — README.md หลักอ้างอิงไฟล์พวกนี้ไว้แล้ว รูปจะขึ้นอัตโนมัติเมื่อดูบน GitHub
   ไม่ต้องแก้โค้ดอะไรเพิ่ม

ไฟล์นี้ (`README.md` ในโฟลเดอร์นี้) ลบทิ้งได้เมื่อใส่รูปครบแล้ว
